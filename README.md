# introduction

If you do not know about the latte panda MU. well its a CM (compute moudule) a credit card sized moudule which can has a cpu, ram and some storage already added onto it so you can get X86 cpus (i3 n305 and n100) with upto 32gb ram. the good thing with this is that you can swap the moudule if it gets a new cpu in the feture oe just take it out and plug it into anorther cariar board and use the same cpu

# what this has

this motherboard is made to be thin as possable so you can make good laptops with it the board contains

**1x SO-DIMM conector** to plug the moudule into

**2x m.2 M-key slot** 1x4 lane slot and 1x2 lane slot

**1x m.2 E-key slot** used for wifi/bt card

**5x usb 2.0** 4x ports and 1 header for expansion and keyboard stuff

**2x usb 3.0** very fast speed

**1x display port** supports upto 8k

**header to plug 2x speakers** add what ever speaker you want

**header to add microphone** add 2x mics (left and right)

**BMS** add whatver battry you want 

**12v fan header**

**cmos battry and chrging indicator**

 **reset switch and power button header**

 **this also has a eDP port which is provided on the moudule itslef to plug in laptop and touch displays**
 only use 12v displays as only 12v is available on that port
